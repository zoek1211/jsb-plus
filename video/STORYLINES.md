# Storylines — jsb-plus 결과 영상 (약 5분)

선택: **A. 질문 하나의 여행** (2026-11-14). B·C 는 나중에 바꿀 때를 위해 남겨 둔다.

## A. 질문 하나의 여행 ✅ 선택
- 장치: 하나의 예시를 끝까지 따라가기 + 교재/우리 비교(잘못된 방식을 지우고 맞는 방식으로 덮어쓰기). 형식: 한 화면이 계속 재배치되는 diff.
- 샘플 질문 "sbb가 무엇인가요?" 가 DB 에 저장 → 목록 → 답변 → 수정 → 추천 → 검색 → 마크다운까지 가는 동안, 정거장마다 교재 방식이 실패(빨간 테스트, 403, 500, 실행되는 스크립트)하고 우리 방식이 초록으로 바뀐다.
- 첫 2초: 답변에 쓴 `<script>` 가 글자 그대로 보이는 상세 화면.
- 비트: 훅 → 과제 소개 → DB → 웹 화면 → 보안 → 새 버전에서 깨진 것 → 테스트 50개 초록 → 마지막 한 줄.
- 룩: GitHub 풍 밝은 바탕, 실제 화면 캡처, 바뀐 한 줄만 강조된 코드 diff.
- 소리: Edge TTS 한국어 내레이션 + (가능하면) 잔잔한 배경음, 테스트가 초록이 될 때 짧은 pop.

## B. 커밋 타임라인 비행
- 57개 태그를 하나의 길로 펼치고 카메라가 따라 이동, 정거장마다 그 커밋의 실행화면과 핵심 변경.
- AI 와 작게 커밋하며 일한 "과정"이 잘 보이지만, 목록처럼 읽히기 쉽다.

## C. 통하지 않은 공격들 (대담한 안)
- 공격자 시점: 다른 사이트의 링크가 글을 지우고, 이미지가 로그아웃시키고, 마크다운 글이 스크립트를 실행한다. 교재 버전에선 성공, 우리 버전에선 실패.
- 기억에 남지만 작업의 1/3 만 다룬다.
